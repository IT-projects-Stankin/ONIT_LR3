# ОНИТ — лабораторные работы

Проект по дисциплине «Основы новых интернет-технологий».

## Лабораторная работа №1

Гостевая книга на FastAPI с последовательным расширением инфраструктуры:

- `lab1/01_memory/` — приложение с хранением сообщений в памяти процесса;
- `lab1/02_postgres/` — PostgreSQL и постоянный том Docker;
- `lab1/03_monitoring/` — Prometheus, Grafana, cAdvisor, postgres-exporter.

Для запуска любого этапа из соответствующего каталога:

```bash
docker compose up -d --build
docker compose ps
```

Перед переключением между этапами выполните `docker compose down` в текущем каталоге, чтобы освободить порт 8000. При запуске мониторинга также используются порты 9090 и 3000.
